# 🛡️ Примеры документов по информационной безопасности (InfoSec)

Добро пожаловать в репозиторий с примерами, шаблонами и обезличенными документами по информационной безопасности.

> **⚠️ Важно:** Все организации, реквизиты, IP-адреса, ФИО и описанные инциденты являются **вымышленными**. Документы приведены исключительно в демонстрационных и образовательных целях. Не используйте их в качестве официальных документов без адаптации под реалии вашей компании.

---

## 🗂️ Направления документов

В репозитории собраны примеры по следующим ключевым процессам ИБ:

*   🛡️ **Предупреждение (Prevention):** Политики, стандарты, регламенты, правила настройки (Hardening).
*   🚨 **Реагирование (Response):** Планы реагирования на инциденты (IRP), инструкции для дежурных.
*   🔍 **Расследование (Investigation):** Отчеты по форензике, разборы инцидентов, журналы аудита.
*   📊 **Анализ (Analysis):** Отчеты об оценке рисков, анализ защищенности, пост-мортем (Post-mortem).

---

## 🏢 Организации (Кейсы)

Документы сгруппированы по папкам компаний. У каждой компании есть ряд своих разработанных документов.

---

## 🚀 Как пользоваться репозиторием

1. Выберите интересующую вас компанию из списка выше.
2. Откройте папку компании и найдите нужный документ.
3. Для ознакомления используйте файлы **`.pdf`** (они открываются прямо в браузере).
